⏪ Rollback

  • Each Lambda runs behind a live alias. Rolling back points the alias at the previous version.

  • The previous PWA build is kept, so the site can switch back to it.

  • Code rolls back; data does not. Schema changes go in two steps (add, then remove later) so the old code still reads them.

  • A model is rolled back through its approved pointer, separately from the app (controlled learning).

  • To verify: what a rollback does to a durable workflow already running. No speed is claimed until it is measured.

💷 What CI costs

Free on a public repo

The standard GitHub-hosted runners, macOS included, are free and unlimited on a public repository (GitHub docs, checked 24 November 2026). GitHub Free limits concurrency instead: 20 jobs at once, 5 of them macOS. Until 24 November MP was private and drew on the org's $12 a month.

MP's CI today

A PR run bills about 9 minutes (each job rounds up to a minute); a merge about 8. On 1 and 2 November MP used 219 Linux minutes and MA 58: setup days, not a normal month.

  • A proposed normal month, 40 PR pushes and 20 merges, is about 520 Linux minutes. On a public repository that costs nothing.

  • Only if the repository went private again would minutes be billed, past a $12 shared allowance: 100 Linux minutes about £0.58, 100 macOS minutes about £5.95.

  • MP203-11, 24 November 2026 (MP-203): the owner picked "Build and unit tests in CI" (pressed on the page). The option read: "Each pull request that touches the Apple app builds it and runs XCTest on a free macOS runner. Maestro journeys and real-device builds stay on your Mac." (Apple testing). Those macOS minutes cost £0 while the repository is public, and about £5.95 per 100 if it went private again.

  • GitHub is not yet in the cost model; it needs a line, planned at £0 with a cap (Cost and the £100 ceiling).

How these figures were reached

  • Public-repository billing and limits: docs.github.com, checked 24 November 2026: standard runners free and unlimited, concurrency limits apply.

  • Prices: docs.github.com, GitHub Actions billing and Actions runner pricing, checked 2 November 2026.

  • Usage: the org's billing usage report for October and November 2026, read 2 November 2026.

  • Pounds use the cost specification's central £0.80 per dollar and 20% tax.

  • While the repository was private: without a payment method GitHub stops runs at the allowance; whether one is on file is not verified.
