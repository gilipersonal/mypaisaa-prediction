OPEN

The Free plan cannot hold the prod gate. On a private repo, GitHub's required reviewers and wait timers need Enterprise, and environment secrets need Pro or Team. So the rule's "owner approves in a protected environment" cannot be built on today's plan. Options:

  • A, free: a release workflow only the owner dispatches, with the sha256 as input, and a prod role that trusts only main and that workflow file. The org has one member today.

  • B: GitHub Team, $4 a user a month (about £3.84): branch protection and environment secrets, still no required reviewers on a private repo.

  • C: GitHub Enterprise, $21 a user a month (about £20.16): required reviewers.

  • D: an AWS CodePipeline manual approval in the prod account. Approvals are not charged, but it is a new managed service, so it needs a costed ADR.

⏪ Rollback

  • Each Lambda runs behind a live alias. Rolling back points the alias at the previous version.

  • The previous PWA build is kept, so the site can switch back to it.

  • Code rolls back; data does not. Schema changes go in two steps (add, then remove later) so the old code still reads them.

  • A model is rolled back through its approved pointer, separately from the app (controlled learning).

  • To verify: what a rollback does to a durable workflow already running. No speed is claimed until it is measured.

💷 What CI costs

$12 a month, shared

GitHub Free for organisations includes $12 of runner time. Every private repo in the org draws on it, MA included. Linux is $0.006 a minute (about 2,000 minutes); macOS is $0.062 (about 193 minutes, 10.3 times Linux).

MP's CI today

A PR run bills about 9 minutes (each job rounds up to a minute); a merge about 8. On 1 and 2 November MP used 219 Linux minutes and MA 58: setup days, not a normal month.

  • A proposed normal month, 40 PR pushes and 20 merges, is about 520 Linux minutes: $3.12, about £3.00. Inside the allowance.

  • Past the allowance, 100 Linux minutes cost about £0.58 and 100 macOS minutes about £5.95.

  • Apple builds run on the owner's Mac, which bills no GitHub minutes (Apple testing).

  • GitHub is not yet in the cost model; it needs a line, planned at £0 with a cap (Cost and the £100 ceiling).

How these figures were reached

  • Prices: docs.github.com, GitHub Actions billing and Actions runner pricing, checked 2 November 2026.

  • Usage: the org's billing usage report for October and November 2026, read 2 November 2026.

  • Pounds use the cost specification's central £0.80 per dollar and 20% tax.

  • Without a payment method GitHub stops runs at the allowance; whether one is on file is not verified.
