Story catalogue and planned acceptance

6 current local story drafts. An actual Jira implementation story and detailed readiness evidence are required before UX; the closure tickets above are planning work, not substitutes.

L5-S01 · Evidence ingestion and structured LLM factors

State: umbrella_requires_decomposition; actual implementation Jira key not allocated. Dependencies: see phase gates.

  • Capture citations/content hashes/publication/known-at/extraction times and rights for news/filings/events/exposures; deduplicate and quarantine untrusted material.
  • Version extraction prompt/model/schema/confidence and tag possible hindsight in retrospective article extraction.
  • News sentiment/factors remain shadow until prospective or justified point-in-time ablation evidence permits approved use.

Contracts: AgentManifest, ToolContract, EvidenceBundle, ClaimReference, ConversationContext, BatchItem, EvalResult, EvalLabel, MemoryNote. Evidence/examples: Evidence/factor contracts; source injection and time-contamination cases; citation audit.

L5-S02 · Bounded direct Anthropic client-SDK agent runtime

State: umbrella_requires_decomposition; actual implementation Jira key not allocated. Dependencies: see phase gates.

  • Specify official Python client-SDK loop on Lambda, direct Claude-hosted inference and typed validated tool results; do not use Anthropic Agent SDK subprocess runtime.
  • Nine reference responsibilities have allowlisted read-only scopes, budgets, timeout/turn/token caps and durable continuation/cancellation; roles need not all invoke an LLM.
  • Agents cannot trade, fetch secrets, alter ledger truth, edit model weights or promote themselves; budget admission precedes calls including evaluations.

Contracts: AgentManifest, ToolContract, EvidenceBundle, ClaimReference, ConversationContext, BatchItem, EvalResult, EvalLabel, MemoryNote. Evidence/examples: AgentManifest/tool schemas; denied-tool/timeout/continuation cases; cost trace.

L5-S03 · Contextual chat and research cards

State: umbrella_requires_decomposition; actual implementation Jira key not allocated. Dependencies: see phase gates.

  • Retain stance/profile/overlap/benchmark/bull-bear/scenario/valuation/earnings cards and shared cross-device conversation context.
  • Bound bull/bear to two arguments plus adjudication; source claims and numerics resolve to permitted evidence and deterministic calculators.
  • Chat cannot bypass forecast eligibility or fabricate missing prices/history; technical detail/glossary expand from concise answers.

Contracts: AgentManifest, ToolContract, EvidenceBundle, ClaimReference, ConversationContext, BatchItem, EvalResult, EvalLabel, MemoryNote. Evidence/examples: Card/conversation API examples; citation/numerical/abstention cases; UX context walkthrough.

L5-S04 · Layered safety and quality evaluations

State: umbrella_requires_decomposition; actual implementation Jira key not allocated. Dependencies: see phase gates.

  • Specify T0 deterministic checks,T1 bounded model cases,T2 end-to-end capability/safety cases plus online checks, sampled judges and owner calibration.
  • Test prompt injection, identity/privacy/cross-env leakage, ungrounded numbers, citation failures, no-trading and budget exhaustion; LLM judges do not replace realised outcomes.
  • Keep eval provenance/cost and human disagreement; approve release thresholds before activation.

Contracts: AgentManifest, ToolContract, EvidenceBundle, ClaimReference, ConversationContext, BatchItem, EvalResult, EvalLabel, MemoryNote. Evidence/examples: Evaluation pack and adversarial corpus; gate thresholds; human-calibration protocol.

L5-S05 · Owner settings, approvals and scope controls

State: umbrella_requires_decomposition; actual implementation Jira key not allocated. Dependencies: see phase gates.

  • Version schemas/ranges for risk/ranking/agent settings; show proposed impact,evidence,cost and rollback before sensitive approval.
  • Record verified owner decisions and reject stale/replayed approvals; denied requests cannot retry endlessly.
  • A configuration change cannot grant broader tools, sources, budgets or infrastructure authority.

Contracts: AgentManifest, ToolContract, EvidenceBundle, ClaimReference, ConversationContext, BatchItem, EvalResult, EvalLabel, MemoryNote. Evidence/examples: Approval/settings state machine; stale/replay and privilege-boundary cases.

L5-S06 · Scoped memory and cache economics

State: umbrella_requires_decomposition; actual implementation Jira key not allocated. Dependencies: see phase gates.

  • Keep owner-visible scoped notes, correction/forget controls, taint and source audit; notes cannot replace ledger values or approved settings.
  • Bound context and cache stable prefixes only within privacy scopes; measure savings and all cache costs.
  • Deletion/correction policy covers note derivatives without deleting required durable financial audit evidence.

Contracts: AgentManifest, ToolContract, EvidenceBundle, ClaimReference, ConversationContext, BatchItem, EvalResult, EvalLabel, MemoryNote. Evidence/examples: Memory/cache schemas and retention join; isolation/forgetting cases; cache cost evidence.

UX states to specify after architecture sign-off

  • Success, empty, loading, partial and unavailable; stale source and insufficient evidence.
  • Permission denied, fresh authentication required, approval pending/expired/rejected and conflicting revision.
  • Offline/reconnecting, delayed job, retry exhausted, partial commit and safe recovery.
  • Privacy mode, keyboard/screen reader, light/dark and reduced-motion equivalents on web and Apple.

Audit, monitoring and cost acceptance

  • Record relevant actor/environment/business IDs, source/config/model versions and immutable approval/change/run evidence.
  • Define signals for failure, lateness, duplicate handling, source age and reconciliation; redact private payloads from operational telemetry.
  • Include source/provider, compute, storage, trace, retry and eval costs in the shared budget; no silent paid fallback.

Exit demonstration and failures

LLM research stays grounded/read-only; numerical models and realised-outcome validation remain separate.

The planned exit demonstration must run the phase user journey plus one permission failure, one stale/partial data case, one duplicate/reconnect/retry case and one recovery path with evidence. Scientific phases additionally prove temporal/data maturity invariants; no invented live accuracy.

Failure/recovery intent: Abort bounded loop,deny tools,quarantine tainted material and return deterministic/abstaining views with a run audit.

No exit is currently certified. Deployment, live activation, model eligibility and owner approval are separate records.
