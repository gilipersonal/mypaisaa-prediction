L7-S01 · Native SwiftUI within React Native shell

State: umbrella_requires_decomposition; actual implementation Jira key not allocated. Dependencies: see phase gates.

  • Swift owns native views,persistence,widgets and secure-device integration; RN shell owns navigation/bridge contracts.
  • Deliver approved adaptive dashboard,holdings,imports,forecast/proof,chat,cost and approval journeys across iPhone/iPad/Duo matrix.
  • Test shared API/event and shell/native schema compatibility and discoverable error/recovery states.

Contracts: NativeBridge, OfflineSnapshot, PushSubscription, DeepLink, ClientState. Evidence/examples: Bridge contract; device/OS acceptance matrix; native snapshots and contract results.

L7-S02 · Offline cache, privacy and accessibility

State: umbrella_requires_decomposition; actual implementation Jira key not allocated. Dependencies: see phase gates.

  • Encrypt/cache only approved data,display per-record age,refetch after reconnect and revoke access/session caches appropriately.
  • VoiceOver,Dynamic Type,reduced motion,focus/chart alternatives and large/adaptive layouts satisfy agreed acceptance.
  • No confidential holdings appear on lockscreen,app snapshots or exported share content by default without approved settings.

Contracts: NativeBridge, OfflineSnapshot, PushSubscription, DeepLink, ClientState. Evidence/examples: Offline/revoked-session tests; native accessibility walkthrough; privacy state matrix.

L7-S03 · PWA/native push and permission fallbacks

State: umbrella_requires_decomposition; actual implementation Jira key not allocated. Dependencies: see phase gates.

  • Implement first-version app/chat,native and PWA push per verified OS/browser capability and user permission.
  • Use durable outbox,dedup/deep links,quiet hours and neutral payloads; denied/background-disabled delivery remains visible in-app.
  • Measure delivery limitations; do not promise instant OS delivery or infer no risk from silence.

Contracts: NativeBridge, OfflineSnapshot, PushSubscription, DeepLink, ClientState. Evidence/examples: Supported-platform evidence; permission/quiet/duplicate/deep-link cases.

L7-S04 · Native capability backlog without hidden scope loss

State: umbrella_requires_decomposition; actual implementation Jira key not allocated. Dependencies: see phase gates.

  • Specify widgets,share-sheet intake,search/deep links,Siri/AppIntents and long-job Live Activities with privacy,availability and cost constraints.
  • Classify each capability launch-required or later activation by explicit owner choice; no silent removal of inherited scope.
  • Keep Android product screens outside current agreed release scope; RN shell does not imply an Android UI.

Contracts: NativeBridge, OfflineSnapshot, PushSubscription, DeepLink, ClientState. Evidence/examples: Capability/release decision table; platform fallback and privacy examples.

UX states to specify after architecture sign-off

  • Success, empty, loading, partial and unavailable; stale source and insufficient evidence.
  • Permission denied, fresh authentication required, approval pending/expired/rejected and conflicting revision.
  • Offline/reconnecting, delayed job, retry exhausted, partial commit and safe recovery.
  • Privacy mode, keyboard/screen reader, light/dark and reduced-motion equivalents on web and Apple.

Audit, monitoring and cost acceptance

  • Record relevant actor/environment/business IDs, source/config/model versions and immutable approval/change/run evidence.
  • Define signals for failure, lateness, duplicate handling, source age and reconciliation; redact private payloads from operational telemetry.
  • Include source/provider, compute, storage, trace, retry and eval costs in the shared budget; no silent paid fallback.

Exit demonstration and failures

First-version native/PWA push fallbacks follow verified platform capability; advanced integrations need an explicit launch/later choice.

The planned exit demonstration must run the phase user journey plus one permission failure, one stale/partial data case, one duplicate/reconnect/retry case and one recovery path with evidence. Scientific phases additionally prove temporal/data maturity invariants; no invented live accuracy.

Failure/recovery intent: Revoke affected session/cache,fall back to in-app notices and stale-labelled read cache; no unsafe offline financial writes.

No exit is currently certified. Deployment, live activation, model eligibility and owner approval are separate records.
