Default to static owner-configurable ordering until owner explicitly approves bounded personalisation; do not inherit autonomous reordering.

**Decision:** Whether taps/corrections/mutes may influence presentation order, and with what consent/retention/reset controls.

- Only first-party owner signals; untrusted documents/news cannot teach preferences.
- Visible learned settings, reset/opt-out and retention; no automatic records/forecasts/ranking/alert-policy changes.
- Deidentify and separately approve any corrected import promoted into an evaluation case.

### IR-02 · Decide export and cross-app retirement boundaries

Treat owner export/reproducibility as a candidate MP contract; do not inherit DNS handover, wealth-tracker retirement or automatic migration.

**Decision:** Required ledger/forecast/audit export formats and any optional MA file interchange.

- Exports pin schema/as-of/provenance and respect owner/environment isolation.
- Creation/access/deletion is audited; no public object URL by default.
- Named later cutover approval precedes any MA job/resource/issue/history retirement.
